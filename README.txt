EXPENSE TRACKER V6 — LONG-TERM FOUNDATION

V6 introduces a stable transaction model:
ID, Date, Type, Merchant/Source, Category, Payment/Account, Amount, Notes, Created, Modified.

Types: Expense, Investment, Income.
Investments have dedicated categories such as Mutual Funds, Stocks, SIP, FD, Gold, PPF, NPS.
The app remains offline-first with local storage and CSV export.
Numbers sync is designed through an Apple Shortcut named "Expense to Numbers".
Recommended Numbers columns match the transaction model.

Install by hosting the folder over HTTPS and using Safari > Share > Add to Home Screen.
